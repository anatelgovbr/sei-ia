# Upgrade do Servidor SEI IA 1.0.x para 1.1.x

Esta transição pertence à estrutura anterior ao monorepo. Use os arquivos e o
script de migração fornecidos pela tag 1.1.x; os comandos atuais `make up` e
`make check` ainda não eram o contrato dessa linha.

## O que mudou

- o acesso aos dados do SEI passou a usar as variáveis `SEI_API_DB_*`;
- `SOLR_USER` e `SOLR_PASSWORD` passaram a compor a autenticação do Solr;
- foram separados os parâmetros dos modelos `standard`, `mini` e `think`;
- a configuração de embeddings passou a exigir chave, endpoint e modelo próprios.

## Procedimento

1. No diretório da 1.0.x, pare somente os contêineres do projeto SEI IA usando o
   Compose daquela versão. Preserve os volumes.
2. Guarde `env_files` em local protegido e fora do checkout de destino.
3. Obtenha a tag 1.1.x e execute
   `migracao/1.0_1.1/migracao_1.0_1.1.py` fornecido por ela, informando o diretório
   protegido quando solicitado.
4. No `env_files/security.env` gerado, preserve as credenciais existentes e
   preencha os novos nomes de Solr, API do SEI, embeddings e modelos de texto.
5. Execute `migracao/1.0_1.1/deploy-externo-1.0-1.1.sh` da tag 1.1.x.

Não use comandos globais que parem ou removam todos os contêineres do host. Não use
`down -v`: o procedimento depende da preservação dos dados existentes.

## Validação

Confirme que os serviços da 1.1.x estão saudáveis e que o SEI consegue consultar a
API configurada. Depois, entre no SEI com um usuário autorizado, abra o Assistente e
envie uma mensagem simples.
