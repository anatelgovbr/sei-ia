# Upgrade do Servidor SEI IA 1.1.x para 1.2.x

Esta transição pertence à estrutura anterior ao monorepo. Use os artefatos da tag
1.2.x; o contrato atual de arquivos na raiz passa a valer somente na transição para
1.3.x.

## O que mudou

- o LiteLLM Proxy passou a centralizar modelos de texto e embeddings;
- os valores de modelo, endpoint, chave e versão de API saíram das antigas
  variáveis `ASSISTENTE_*` e passaram para
  `llm_config/litellm_config.yaml`;
- o Redis foi adicionado para cache;
- o WebSearch passou a aceitar configuração opcional do Azure AI;
- o volume antigo de jobs do Airflow deixou de fazer parte da composição.

Os defaults não sensíveis também mudaram nesta linha: timeout da API do Assistente,
tamanho de chunks, concorrência do Airflow e limites do Assistente. Use os arquivos
da 1.2.x, sem copiar o arquivo de defaults da 1.1.x sobre eles.

## Migração dos modelos

Para cada alias existente na 1.2.x (`standard`, `mini`, `think` e `embedding`),
transfira do `security.env` da 1.1.x para o YAML da 1.2.x:

| Campo no LiteLLM 1.2.x | Origem na 1.1.x |
|---|---|
| `model` | nome/deployment do modelo correspondente |
| `api_base` | endpoint do modelo correspondente |
| `api_key` | chave do modelo correspondente |
| `api_version` | versão da API OpenAI/Azure |

## Procedimento

1. Pare somente a stack 1.1.x, sem remover volumes.
2. Guarde `env_files` em local protegido.
3. Obtenha a tag 1.2.x e execute
   `migracao/1.1_1.2/migracao_1.1_1.2.py`, apontando para a configuração anterior.
4. Revise o `env_files/security.env` gerado e preserve os usuários e senhas dos
   serviços persistentes.
5. Preencha `llm_config/litellm_config.yaml` com os quatro aliases da tabela, sem
   deixar placeholders.
6. Se o WebSearch for usado, preencha as variáveis do Azure AI; caso contrário,
   mantenha a funcionalidade desativada no SEI.
7. Execute `migracao/1.1_1.2/deploy-externo-1.1-1.2.sh` da tag 1.2.x.

## Validação

Confirme o estado dos serviços e os aliases no LiteLLM. Entre no SEI com um usuário
autorizado, abra o Assistente e envie uma mensagem simples.
