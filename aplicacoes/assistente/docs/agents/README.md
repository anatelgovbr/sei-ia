# Agentes / Agents

## Conteúdo

1. [Visão Geral](overview.md) - Agente Session e arquitetura ativa
2. [Busca Web](websearch.md) - Ferramentas de pesquisa e coleta de páginas

RAG, pergunta e seus auxiliares diretos permanecem em `scripts/legado/` (consulte `scripts/legado/docs/agents/question-handler.md`). Os demais agentes clássicos foram excluídos.

## O que são Agentes?

No contexto do SEI-IA, agentes são componentes especializados que executam tarefas específicas no workflow de processamento de requisições.
